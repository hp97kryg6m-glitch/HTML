Bash Commands I have Learnt

1. Touch

File Creation

The touch command creates a new, empty file. If the file already exists, it simply updates the files's last-modified timestamp instead of changing its content.

Stntax: touch filename

Example: touch notes.txt

Output: (no output - the file notes.txt is created silently in the current folder)

2. mkdir

Folder creation

The mkdir command creates a new, empty folder (directory) at the location you specify.

Syntax:mkdir foldername

Example:mkdir project

(no output - the folder project is created in the current directory)

3. cd

Changing directory

The cd command changes the current working directory, moving you into a different folder in the terminal.

Example:cd project

Output: (prompt changed to show you are now inside ~/project)
